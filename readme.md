# YaCut — сервис сокращения ссылок и загрузки файлов

## Описание проекта

YaCut — это веб-сервис для создания коротких ссылок.

Проект позволяет:

- создавать короткие ссылки по API;
- задавать собственный идентификатор короткой ссылки;
- получать оригинальную ссылку по короткому идентификатору;
- загружать файлы через веб-интерфейс и автоматически создавать короткие ссылки на загруженные файлы.

Проект реализован как Flask-приложение с поддержкой REST API и пользовательского интерфейса.

### Как развернуть проект Yacut:

1. Клонируйте репозиторий

```
git clone https://github.com/LiliyaShangaraeva/async-yacut#
cd yacut 
```

2. Создайте и активируйте виртуальное окружение

```
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

* Если у вас windows

    ```
    source venv/scripts/activate
    ```

3. Установите зависимости

```
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```

4. Создайте в директории проекта файл .env с четыремя переменными окружения:

```
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key
DB=sqlite:///db.sqlite3
DISK_TOKEN=your_disk_token
```

DISK_TOKEN — это токен для доступа к API Яндекс.Диска.
Чтобы его получить:

- Перейдите на https://oauth.yandex.com/client/new/
- Авторизуйтесь и создайте приложение
- Скопируйте OAuth-токен и вставьте в DISK_TOKEN

5. Создайте базу данных и примените миграции:

```
flask db upgrade
```

6. Запустите проект

```
flask run
```

После запуска приложение будет доступно по адресу:

```
http://127.0.0.1:5000/
```

## API
Создание короткой ссылки

```
POST /api/id/
```

Получение оригинальной ссылки по короткому идентификатору

```
POST /api/id/<short_id>/
```

## Веб-интерфейс

- Главная страница — создание коротких ссылок

- Страница /files — загрузка файлов и генерация коротких ссылок на них
